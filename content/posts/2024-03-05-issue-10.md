这个博客是用来输出一些我的想法，总结出来的一些经验的，希望无论是什么内容都能帮助到你给你以启发。

本博客是由[gitblog](https://gitblog.io/)搭建的，有点类似于给 github 的 issue 界面套了层皮肤。之前使用过几个别的博客网站或者其他项目的 github 网页。但一方面是我完全不愿意去了解网页排版布局 html 等内容的规则，也不在乎网页的美观程度，另一方面是往往好看的博客会增加提笔的心理负担：进入后台输入的麻烦程序会劝退我，输 markdown 的内容需要特殊的软件也很麻烦。

而 gitblog 则不同，它完全依托 github。输入界面就是新建 issue 界面，简单直接可以调用 markdown 能力而不需要记住语法，可以快速预览 markdown 的结果，自带图床可以截图直接粘贴，有直接提供 RSS 订阅的能力（虽然估计没人会订阅），有简洁的主页设计不需要操心设计，有基于 issue 的评论机制。

不过也有一些缺点
1. 没有标签机制，不方便分类
2. 没有中文的或者其他形式的日期或者排序机制
3. 没有良好的主页，或者置顶能力

未来也许会更换其他博客，也许不会。
